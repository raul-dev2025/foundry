===========================================
Fase 0: Preparación e Hito Base (GOLDEN-00)
===========================================

Objetivos de la Fase
====================

1. Creación e inicialización del repositorio de control de código ``foundry``.
2. Definición de la estructura base para la documentación en formato **reStructuredText (rST)**.
3. Creación del punto de restauración inicial **GOLDEN-00** sobre la capa VDO (*reflink*).

Procedimiento Técnico
=====================

El repositorio se ha inicializado con la estructura estándar para separar
scripts, documentación y configuraciones:

* ``docs/``: Documentación técnica del laboratorio.
* ``scripts/``: Herramientas de automatización de entornos y pruebas.
* ``config/``: Archivos de configuración de build, kernel y herramientas.
